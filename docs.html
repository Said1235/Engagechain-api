EngageChain API

A deployable REST API that wraps the EngageChain Intelligent Contract on GenLayer. Submit opinions, trigger AI evaluation with on-chain consensus, and read verified results — from any application.

v2.0.0 Vercel Railway Heroku Node.js VPS CORS enabled

Quick Start

1 — Clone & install

Terminal
git clone https://github.com/Said1235/Engagechain-api.git
cd Engagechain
npm install

2 — Configure

.env
# Required
CONTRACT_ADDRESS=0x15322146FdF38a93F5F4eBB88499A49A2199A6f2

# Optional — defaults to GenLayer studionet
GENLAYER_RPC=https://studio.genlayer.com:8443/api

# Optional — fallback signing key for write operations
PRIVATE_KEY=0xyour_private_key_here

3 — Start locally

Terminal
node server.js
# → http://localhost:3000

4 — Make your first call

cURL
curl http://localhost:3000/opinions/count
Response
{
  "ok": true,
  "total": 7
}

Authentication

Read endpoints (GET) are public — no key required. Write endpoints (POST) need a GenLayer wallet private key for signing transactions.

Studionet accounts are free. If no key is provided, the API auto-generates a fresh funded account for every request. This is fine for testing — for production, set a persistent key.

Option A — Header per request

cURL
curl -X POST http://localhost:3000/opinions \
  -H "Content-Type: application/json" \
  -H "X-Private-Key: 0xyour_private_key" \
  -d '{"text": "AI should be open source"}'

Option B — Environment variable (shared key)

.env
PRIVATE_KEY=0xyour_private_key_here

Get a free key from GenLayer Studio — create an account and copy the private key.

POST /opinions/:id/evaluate/external Validate with external AI

Store your own AI analysis on-chain. GenLayer validators verify it's well-formed JSON — they don't re-run the AI.

Body fieldTypeDescription
analysisobject|stringrequiredYour AI analysis. JSON object or string, max 10000 chars
waitstringoptional"accepted" | "finalized"
Node.js — bring your own AI

const myAnalysis = {
  summary: "The author argues for democratic AI governance",
  sentiment: "positive",
  key_points: ["Transparency", "Accountability"],
  ai_recommendation: "Publish as open standard",
  confidence_score: "0.95"
};

// Step 2: store on-chain via EngageChain API
const res = await fetch(`https://your-api.vercel.app/opinions/${id}/evaluate/external`, {
  method: 'POST',
  headers: { 'Content-Type': 'application/json', 'X-Private-Key': key },
  body: JSON.stringify({ analysis: myAnalysis })
});

Custom Parameters

Filtering & Pagination

All options combined
# Get the 10 most recent finalized opinions, only id+text+verdict fields
GET /opinions?status=finalized&limit=10&offset=0&fields=id,text,verdict

Metadata on-chain

Attach arbitrary data to any opinion when submitting. It's stored on-chain and returned in GET /opinions/:id.

Node.js
await fetch('/opinions', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json', 'X-Private-Key': key },
  body: JSON.stringify({
    text: "Universal basic income is necessary",
    metadata: {
      tags: ["economics", "policy"],
      author_handle: "@said1235",
      app_version: "1.0.0"
    }
  })
});

Parse AI response automatically

Before (ai_response is a string)
GET /opinions/0
→ "ai_response": "{\"summary\":\"...\",\"sentiment\":\"positive\"}"
After (?parse_ai=true)
GET /opinions/0?parse_ai=true
→ "ai_response": { "summary": "...", "sentiment": "positive" }

wait parameter

Control when a write request returns. "accepted" returns faster (after initial consensus) while "finalized" waits for the full finality window.

Body
{ "text": "My opinion", "wait": "accepted" }
// Returns in ~10s instead of ~60–120s

Error Handling

All errors return HTTP 4xx/5xx with a consistent JSON body.

Error response
{ "ok": false, "error": "body.text is required (string)" }
StatusMeaning
400Bad request — missing or invalid body parameter
404Unknown endpoint
500Contract error, RPC timeout, or network issue
Node.js — robust error handling
const res = await fetch('/opinions', { ... });
const data = await res.json();

if (!data.ok) {
  console.error('API error:', data.error);
  return;
}
console.log('Opinion ID:', data.opinion_id);
